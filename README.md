# 💧 Water Bucket Puzzle Solver

This is a simple and beautiful web-based visualization for solving the classic **Water Bucket Puzzle** using **Breadth-First Search (BFS)**.

> "Given two buckets of different sizes, how can you measure exactly X liters?"

---

## 🚀 Features

- 🌊 Animated water level updates
- ✅ Validates user input with helpful error messages
- 📘 Step-by-step BFS solution
- 🎨 Smooth, responsive layout with **pure CSS (no frameworks)**

---

## 🧠 How It Works

This project uses a **BFS algorithm** to find the shortest sequence of steps to reach the target water amount. It simulates:

- Fill bucket
- Empty bucket
- Pour from one bucket to another

Then animates each step visually with 2-second delays.
